# 4c ユーカリ／ミント

添付「コーネル式ノート UI設計.html」4cを実装前にデザイン基準として採用。

背景 #F0F6F4、ナビ #E4F0EC、紙 #FFFFFF、文字 #12211D、補助 #4E6862、アクセント oklch(0.55 0.09 175)、選択 #DCEFEA。細い境界線、8–12px角丸、控えめな影。緑は選択・保存・完了に使用。

PCは左ナビと中央ワークスペース。ノート上段はCUE 28%・NOTE 72%、下段はSUMMARYとACTION。日本語システムサンセリフ、本文16px・行高1.8。Lucide線画アイコンと日本語ラベルを併用。

ログイン→コレクション別一覧→ノート編集。空状態に作成案内。保存は明示操作・Ctrl/Cmd+S、未保存状態の移動を確認。保存中は編集を一時ロック。

スマートフォンはナビを上部に折り返し、問い／ノート／まとめをタブで切り替える。44pxの操作領域、focusリング、ラベル付き入力。色だけで状態を伝えない。

共有は7日間の閲覧リンク。発行前に公開範囲を説明。所有者が解除可能。共有画面は閲覧専用。

品質レポートは日本語Given/When/Thenと各段階のスクリーンショットを左右に並べ、全ケースを常時展開する。

品質レポートの入口は実測結果のサマリーカードとし、E2E・静的解析・単体/結合テスト・カバレッジ・設計書を個別ページへ分ける。E2EはPCで左280pxの階層ナビ（実行環境→suite→ケース）、右に全ケースのGWTと画像を常時展開する。モバイルでは一覧を本文の上に置き、横スクロールを生じさせない。画像は拡大ダイアログと原寸リンク、Esc・閉じる操作・元のリンクへのフォーカス復帰を持つ。成功/失敗/未実行を文字で示し、緑色だけで判別させない。

設計書サイトはAstro Starlightの白背景・ユーカリ色で統一する。左にAPI／DB／インフラ／テスト／要件の章構成、中央にHTML化した仕様と図、右にページ内目次、上に全文検索を表示する。品質サマリーへ戻れるリンクを常設する。APIの6文書は同じAPI配下へまとめる。C0は命令網羅、C1は分岐網羅として実測分母・分子を示し、未計測とゼロを区別する。

タスク一覧は左ナビの「すべてのタスク」から開く。既存のユーカリミント配色・余白・文字サイズを引き継ぎ、未完了／完了の切り替え、内容とノート名の検索、期日、所属ノートへの導線を一画面に表示する。編集は所属ノートのエディターで行い、一覧へ戻ると最新状態を取得する。
