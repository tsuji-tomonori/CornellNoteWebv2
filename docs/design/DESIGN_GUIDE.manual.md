# 4c ユーカリ／ミント

添付「コーネル式ノート UI設計.html」4cを実装前にデザイン基準として採用。

背景 #F0F6F4、ナビ #E4F0EC、紙 #FFFFFF、文字 #12211D、補助 #4E6862、アクセント oklch(0.55 0.09 175)、選択 #DCEFEA。細い境界線、8–12px角丸、控えめな影。緑は選択・保存・完了に使用。

PCは左ナビと中央ワークスペース。ノート上段はCUE 28%・NOTE 72%、下段はSUMMARYとACTION。日本語システムサンセリフ、本文16px・行高1.8。Lucide線画アイコンと日本語ラベルを併用。

ログイン→コレクション別一覧→ノート編集。空状態に作成案内。保存は明示操作・Ctrl/Cmd+S、未保存状態の移動を確認。保存中は編集を一時ロック。

スマートフォンはナビを上部に折り返し、問い／ノート／まとめをタブで切り替える。44pxの操作領域、focusリング、ラベル付き入力。色だけで状態を伝えない。

共有は7日間の閲覧リンク。発行前に公開範囲を説明。所有者が解除可能。共有画面は閲覧専用。

品質レポートは日本語Given/When/Thenと各段階のスクリーンショットを左右に並べ、全ケースを常時展開する。
